# 07 · 脑洞、世界观、灵感与 AI 写作

> 用户说没灵感、想不出脑洞、世界观搭不好，或要用 AI 协作写作时，加载本文件。

## 一、脑洞四类

穿越、重生、系统、老爷爷只是标配，不叫脑洞。**真脑洞八个字：标新立异，另辟蹊径。**

1. **金手指类**——不是「有个系统」而是系统跟别人不一样；
2. **剧情类**——我被困在同一天一千年；
3. **设定类**（最高级）——斗罗的武魂、诡秘之主的魔药体系；顶级作者自己创造世界观和规则；
4. **角色类**——主角直接不是人。

## 二、脑洞写长三招

1. **穷尽规则的边界**——看到每个人头顶的余额：余额指银行卡还是全部身价？破产是瞬间归零还是缓慢下降？杀掉一个人余额会转移吗？开始追问规则边界，世界观就自动扩张了；
2. **建立需求升级阶梯**——初期用脑洞解决温饱，中期发现脑洞背后隐藏着更高级力量，后期对抗世界级危机；
3. **侧写与连带反应**——全人类缩小一百倍：原本普通的家猫变成哥斯拉般的巨兽，剧情就不再只是我怎么活下去，而是人类文明如何重建。

## 三、世界观三招

1. **资源分配与权力循环**——所有人最想要的是什么？谁垄断了它？冲突是世界观自己长出来的：如果世界里人人都能随手变出黄金，黄金就不再是货币；
2. **链式反应**——初级火球术就能烧开一锅水，这个世界还会发明蒸汽机吗？空间传送阵随处可见，物流行业和战争模式都会天翻地覆；
3. **文明的共识**——封建修仙世界公认强者为尊，路人看到强者欺负弱者应该冷漠或敬畏，而不是现代人的见义勇为。

**不要创造一个背景板，要创造一个生态系统。**

## 四、灵感五招

1. **关键词符合法**——三个抽奖箱：职业 + 金手指 + 核心矛盾，随机抽三个硬捏在一起；
2. **万物皆可系统化**——给平凡小事强行加上离谱的系统规则；
3. **经典结构旧瓶装新酒**——创意的本质就是排列组合；
4. **经典内核反杀发**——把退婚流 180 度反转；
5. **短视频评论区情绪抓取法**——点赞最高的评论代表当下读者最强烈的渴望和最深的怨念。

## 五、新手七步

大道至简只抓一条主线 / 兴趣是最好的发动机 / 在你的主场里写故事（学生写校园、打工人写办公室）/ 经典 CP 永远香 / **一句话说明白你的故事**（一个什么样的主角 + 为了什么目标 + 做了哪些努力 + 遇到哪些越来越强的困难 + 最后怎么样了）/ 找到你的嘴替风格 / 用一个个小情节把故事喂饱。

## 六、AI 写作的五福五劫

### 五个好处

疯狂的生产力 / 降维打击般的资料整理 / 近乎无限的灵感库 / 让人头秃的起名和设定 / 降低全行业门槛。

### 五个致命缺点

没有灵魂抓不住真正的爽点 / 人设极易崩塌且严重同质化 / 长线后继无力 / 平台风险（审核算法一眼识别 AI 风格）/ 摧毁创作者个人风格。

**结论：AI 不会取代有灵魂有独特风格的创作者，但会淘汰那些只会复制粘贴的低端写手——创作的灵魂还在你这里，AI 只是辅助工具。**

观念层面：读者看书都一目十行的时代，平台要的是日更万字的产能量；纯手工四千字在算法推荐面前连门槛都摸不到。开机甲火拼的时代，别光着膀子拿冷兵器上战场。

## 七、AI 味识别与去味

### AI 文三大识别特征

1. 动不动「他嘴角勾起一抹弧度」；
2. 说教感强，动不动升华主题；
3. 全是假大空形容词，没有真人的情绪呼吸。

其他漏馅点：句子过于华丽没有停顿感 / 只有「眼神碎裂气氛凝重」没有具体细节 / 逻辑太完美人物反应永远合理。

### 去 AI 味核心

不是改几个词，而是「**故意弄脏**」——把过于工整的句子打断，加一点卡顿、情绪偏差和多余感官细节，让人物反应不那么完美。宁可写得没那么漂亮，也要写得像人。

### 工作流原则

1. 选「随正文生成即去味」模式（输出即去味后，所见即所得效果最好），不要先出原稿再返工去味；
2. 生成后按三大特征逐条检查，人工微调；
3. 实操顺序：AI 出骨架与分支（跑通 N 套分支剧情挑最刺激的那条）→ 亲笔写情绪密度最高的前三章与高潮章 → 全篇去味微调。

## 八、手机写作三痛点与解法

1. 灵感来了手速跟不上（备忘录敲两行就断）→ 用能即时记录的 AI 工具；
2. 大纲和章节在手机上越改越乱 → 工具化管理；
3. 碎片时间一卡文就滑走 → 需要「马上给到下一步」的工具。

核心结论：手机写小说不是不能写，是习惯和工具没配对。

## 九、给用户头脑风暴时的标准动作

1. 先问三个坐标：热爱度（有语感和表达欲的领域）/ 擅长点 / 市场风向，取交集；
2. 用灵感五招各生成 2-3 个候选，让用户挑；
3. 对挑中的候选立刻用「一句话核心四问」（是谁/要什么/谁拦着/失败会怎样）和「脑洞写长三招」压力测试，判断能不能写长；
4. 能写长的进 `assets/story-bible-template.md`，不能写的当场毙掉，不可惜。
