# 08 · 市场商业化、拆书、素材库与职业心态

> 用户问题材选择、数据差要不要切、怎么拆书、怎么仿写、签约策略、全职决策时，加载本文件。

## 一、网文八股文六大模块

黄金三章 / 金手指 / 脸谱化角色 / 升级流节奏 / 密集爽点 / 套路化冲突。

你眼中的垃圾八股文，其实是一套打磨了二十年的精密商业收割逻辑；不是编辑想签八股文，是市场只给八股文付钱。新人先吃透八股文，再谈创新——**套路是主线，创新是判笔**。

## 二、写什么最赚钱

现在最能赚大钱的题材不是逃避现实，而是**把现实用一种极端荒诞的方式包装起来**。《没钱修什么仙》写的是修仙版衡水中学，《苟在初圣魔门当人材》对标的是职场——上学和上班是压在当代年轻人身上的两座大山，谁都躲不了。

过去经济好大家看英雄救美，现在「能活着下班就不错了」——这背后不是作者没想象力，是整个社会情绪的投射。

## 三、选题三招

1. **找到优势**——你喜欢的题材你真的写得出来吗？新手最大误区是把阅读偏好直接等同于创作能力；要找最有语感和表达欲的领域；
2. **三维坐标定位法**——热爱度 × 擅长点 × 市场风向的交集；
3. **压力测试**——启明测试（放开头到公开平台看点击）、大纲压力测试（按 03 文件逆推法搭大纲）、进品测试。

**网文选择大于努力**——适合你的题材像自带动力的跑车，不适合的像在沼泽地负重前行。

## 四、月入过万的四种职业认知

1. 网文不是文学，是服务型娱乐产品；
2. 稳定更新和工业化生产线——勤奋可以吊打天才，套路和模板让高手像填空一样生产；
3. 数据思维永远大于「我觉得」——盯着点击率、留存率、追读数修正大纲；
4. 对抗平庸的本能——你必须给读者一个非看你不可的理由。

## 五、番茄三大天坑

1. **方向跑偏自我感动**——网站签保底是买你的长板，不是让你去补短板；
2. **书名文艺等于慢性自杀**——书名必须在两秒钟之内告诉读者核心卖点和文章风格；
3. **更新摆烂挑战平台算法**——稳定更新不是优点，是职业素养：你今天断了，读者跑了推荐没了，第二天再想捡回来，没你的位置了。

## 六、拆书：四维度与三步法

### 选书原则

拆近不拆远、拆准不拆砸——拆和你同频道同流派且最近才火的新书（新书榜），别拆大神老书（套路已无形，学不来）。

### 拆书四维度

1. **拆大纲与节奏**——每章一句话概括，重点拆前三章，数高潮分布；拆完会发现爆款结构惊人相似；
2. **拆人设**——标签化、核心诉求、互动关系；
3. **拆情绪**——边看边标记哪里爽哪里憋，识别章末钩子；
4. **拆文笔**——对话无废话、打斗的动词、金句摘录学语感。

### 拆书三步法（可配合 AI）

1. **粗拆结构**——只看前三章或前一万字，把每章冲突点、期待感、爽点标出（开头 200 字/500 字/1000 字各写了什么）；
2. **细拆爽点与节奏**——找一个大爽点，往前看铺垫了多少字、反派嚣张多少、主角反击多少，节奏紧不紧、信息密度够不够；
3. **AI 初筛 + 人工微调**——先用工具输出拆解报告（人物关系、主线冲突、爽点位置、节奏分析），再人工校正。

### 绝招：还原与重写

找最精彩的情节不看原文用自己的话重写，再对比原文——对比的挫败感就是进步最快的时刻。

### 拆书纪律

拆书是为了写节奏，不是抄情节——抄情节会被平台和读者识破，得不偿失。拆完必须反推：「如果我是作者，这里怎么改得更狠、更快、勾子更深？」拆人家的神，不是人家的形。拆十本同类型书，大纲水平明显上一档。

## 七、借鉴与洗稿的分水岭

版权法的「思想表达二分法」——「被退婚」是思想，全盘照搬特定描写和逻辑节奏叫洗稿。

高级的借鉴：

1. 拆解底层逻辑更换外在皮壳（借魂不借形）；
2. 多点跨圈融合；
3. 变量切入。

高手仿写只仿写一个东西——**情绪内核**（《斗破苍穹》的内核是世态炎凉：在你价值最高的时候给你最甜的糖，在你失去利用价值时给你最狠的刀）。仿写精髓 = 一个情绪的引爆点 + 极致的前后反差。

## 八、素材库四模块

写作不是从零到一的艺术创作，而是从一到一百的资源整合——素材库就是弹药库。

1. **人设标签库**——不要记流水账要记矛盾点：「一个极度迷信科学的道士」；
2. **巨型钩子库**——把让你产生「卧槽」感觉的转折点和热梗提炼成一句话扔进仓库；
3. **金句共鸣库**——记下来目的是拆解它的逻辑；
4. **对标库**——把情绪曲线记录下来，卡文时翻开看大佬怎么处理。

## 九、职业心态

### 月入 0 到大神最大的五个坑

闭门造车 / 盲目跟风 / 黄金三章与完美主义 / 人设工具人 / 依赖灵感和心态崩溃。

### 五种不适合写小说的人

完美主义患者 / 想赚快钱的投机客 / 玻璃心敏感者 / 自恃清高的说教者 / 三分钟热度缺乏自律。

### 四类写网文圣体

重度白日梦患者 / 逻辑强迫症患者 / 情绪敏感的共情狂魔 / 极度固执的一根筋（前三类是天赋，这是神格）。

### 止损意识

平台是精密筛选机器，数据不行算法直接宣判死刑。拿着每天几毛钱稿费硬撑到一百万字，只是在把一盘散沙堆成更大的废稿；一本死书真正摧毁的是写作心情。职业作者的核心能力就四个字——数据不行，停笔、复盘、拆解前面的钩子哪里掉了，然后带着教训开新书。**开一本扑街书只要一秒，逃避失败会浪费整整半年。**

### 日更万字心法

1. 把思考和执行彻底分开——开写前花 15 分钟列细纲；
2. 扣掉删除键——写作模式和审查模式彻底分开，一边写一边改等于不断踩油门和踩刹车；
3. 物理启动仪式——泡一杯特定口味的咖啡、播放同一首纯音乐，做完一套特殊动作就是告诉大脑「该战斗了」。

### 七天签约攻略

| 天数 | 任务 |
|---|---|
| 第一天 | 精准定位锁定爆款赛道：像猎人一样研究榜单，拆解一本爆款的开头三万字 |
| 第二天 | 灵魂驻入打造黄金人设与大纲：四个人设卡 + 三百到五百字简纲 |
| 第三至五天 | 极限冲刺心流写作一万字：完成比完美重要 |
| 第六天 | 魔鬼修改为文字镶上钩子：朗读 + 植入钩子 |
| 第七天 | 最终封装自信投稿：选工作日上午，投完马上接着写第二章 |

## 十、可执行行动清单（每本书、每一章的开工前自查）

### （一）开篇动笔前

- [ ] 用一句话说清主角终极目标（具象、带数字与对象）
- [ ] 先定结局，再倒推中间埋什么线、在哪冲突、哪反转
- [ ] 拆出四个关键转折：拽出生活 / 回不去 / 真相碎认知 / 最难选择
- [ ] 确认前三章能立住三句话：主角是谁、要什么、最大麻烦是什么
- [ ] 设计第一章：钩子（极限冲突当下）→ 中段亮底牌 → 章末断章
- [ ] 书名公式检查：具体爽点 + 巨大反差 + 核心身份；简介前三行有悬念

### （二）每一章写作中

- [ ] 本章主角最想得到什么？谁在拦着？付出什么代价？章末留什么新问题？
- [ ] 本章结束读者会不会想知道下一章结果？（不会就重写）
- [ ] 弹簧压够了再打脸；大战后给呼吸感；情绪最高点断章
- [ ] 对白检查：有没有情绪标签、信息倾倒、千人一调？
- [ ] 反派是否走在「最优解」上？主角反击是否付了代价？
- [ ] 上一个冲突解决时，是否已埋下第二个冲突的影子？

### （三）卡文时

- [ ] 先停下来回答「本章必须得到/失去什么」，目标定死再写
- [ ] 人物 ooc 就先写符合人设的真实反应，再让剧情顺着走
- [ ] 写腻了就换视角 / 丢意外 / 拉高冲突强度
- [ ] 还卡就上暴力四招：变量侵入 / 极限施压 / 终点倒推 / 伏笔回收
- [ ] 任何时候别硬写——卡住了还硬写才可怕

### （四）用 AI 时

- [ ] 开启「随正文生成即去味」，不要事后返工
- [ ] 生成后检查三大 AI 特征（嘴角勾弧度 / 升华说教 / 空壳形容词）
- [ ] 人工微调目标：直出人工率 86% → 100%
- [ ] 拆书选同赛道新书；拆节奏不抄情节
- [ ] 手机写作配即时记录 + 卡文即问的工具

### （五）长期创作观

- [ ] 数据不行果断止损：停笔、复盘、找钩子掉点、开新书
- [ ] 新人先练冲突与欲望（骨头），再磨文笔（血肉）
- [ ] 每写完一章做四问自查；每写完一本书做一次完整复盘
- [ ] 稳定更新是职业素养，不是优点
