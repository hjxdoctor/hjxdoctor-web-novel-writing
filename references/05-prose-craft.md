# 05 · 文笔与描写：把文字变成摄影机

> 用户说文笔干巴巴、描写没画面感、动作戏软、AI 味重时，加载本文件（AI 味部分配合 07 文件使用）。

## 一、核心黄金法则：要展示，不要讲述

「他很生气」是讲述（信息标签）；「捏紧茶杯泛白、咔嚓碎裂、茶水顺着指缝滴下、死死盯着对方」是展示（拍电影）。

四招：

1. **扔掉抽象形容词写身体反应**——恐惧 = 冷汗透背、双腿灌铅、喉咙卡棉花；
2. **动词才是灵魂**——跨、抽、扇、飞、砸；
3. **调动所有感官**——写饿 = 胃里像攥紧、唾液酸浆；
4. **侧面烘托，一切景语皆情语**。

## 二、三个笔力公式

1. **镜头推拉法**——用角色行动展示，全程不说一个「可爱」；
2. **感官叠加 + 结果聚焦法**——不写风大，写大树连根拔起像草飞上天；不写恐惧，写看着冰箱撞碎胸口；
3. **人设标签硬凿法**——先定绝对核心标签，用无数细节重复强化，深入人心后用「封神宣言」一句话引爆（「剑来」）。

## 三、好文笔的四个维度

旁白（越简洁越好）→ 画面感（一台摄像机）→ 思想（主角的吐槽、计划、分析）→ 情绪（最高级是把情绪藏起来——写愤怒不用写愤怒两个字，写瓢泼大雨中孤身一人、指甲深深掐进肉里）。

情绪就像犹抱琵琶半遮面的美人，若隐若现的撩拨才最动人。

两个神级技巧：

- **环境交互**——一个喷嚏就让人物和环境产生物理连接；
- **一笔多用**——一段话同时完成环境交互、立人设、引感情线、埋伏笔。信息密度是接近大神的分水岭。

## 四、电影叙事五手法

1. **蒙太奇剪辑法**——杀死无用转场，不相关镜头通过剪辑拼出新意义；
2. **冷开场**——第一张第一句话就要是冲突的果；
3. **摄影视觉化**——形容词堆砌留不下痕迹，电影画面感的文字像胶片自动播放；
4. **猫咪法则**——主角出场做一件展现人性闪光点的小事，观众前一秒就站在他这边；
5. **麦格芬与钩子**——驱动主角和观众持续关注的神秘物件，必须始终在线。

## 五、精简与过滤词清理

删掉「他心里想」「他不仅感到十分震惊」这类**过滤词**——它就像无形的屏障，把你和读者硬生生隔开。真正高手的写作是让读者完全取代「我」，直接用我的眼睛去看、我的耳朵去听。

合并情绪词与对话框，忌「情绪 + 对话 + 动作」的套娃式复读。

## 六、动作戏三招

1. **动词降维与细节放大**——「躲过去」变成「把头猛地往左偏了三公分，拳风刮得脸颊生疼」；「重拳打飞」写成骨头碎裂的声音清脆可闻；
2. **环境互动与物理反馈**——落叶化粉、地板龟裂、碎石刮脸。动作本身是雪白的，动作产生的后果才是震撼的；
3. **视线剪影**——远景切入 → 中景穿梭 → 特写近景 → 主观镜头拉远，把文字变成摄影机。

## 七、小说与短剧的区别（作家转编剧须知）

- 小说是文字艺术可以无限放大内心世界；剧本是视觉艺术，没画出来的东西就是不存在的；
- 小说是做加法，剧本是做减法（每一句台词要么推进剧情要么展现人设）；
- 小说靠悬念和期待，短剧靠情绪和即时爽感（每 30 秒必须给一次情绪反馈）。

## 八、文笔诊断标准动作

用户给文稿求文笔提升时，按顺序检查并给出「改前 vs 改后」：

1. 圈出所有抽象形容词与情绪标签词（愤怒/悲伤/震惊）→ 替换为生理反应或动作；
2. 圈出过滤词（心里想/感到/不禁）→ 删除，让描写直接发生；
3. 检查动词强度——能否换成更具象的动词（跨、抽、扇、砸）；
4. 检查感官调用——这段有没有视觉/听觉/触觉/嗅觉中的至少两种；
5. 检查信息密度——能否一笔多用（一段同时干环境交互+立人设+埋伏笔）；
6. 检查景语是否皆情语——环境描写是否在替人物说话。
