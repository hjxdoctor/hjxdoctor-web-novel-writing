# 04 · 人物塑造：主角、对话、反派与感情戏

> 用户要立人设、写对话、设计反派、写感情戏，或人物「立不住/脸谱化/ooc」时，加载本文件。

## 一、人设三支柱

1. **核心动机**（角色的发动机）——《斗破苍穹》萧炎前期的动机就是洗刷废物之名，像一根刺扎在心里；
2. **外在目标**（导航仪）——必须清晰具体且有时间限制；
3. **致命弱点**——读者永远不会爱上一个完美无瑕的神，他们爱的是有缺陷的人。

三根支柱之上再穿「**反差感**」这件魅力外衣（杀人如麻的刀客私下是无可救药的猫奴）。

**主角必须有一条清晰可见的成长线**；配角更强调功能性——动笔前先问自己他出现在故事里是为了什么。

## 二、立人设四法则

1. **制造极致反差**——矛盾感才是吸引力（杀人不眨眼的刀客动手前要洗手眼睛；表面唯唯诺诺的暖男关上门是幕后操盘手；高冷之花为半块桂花糕跟灵虫抢食）。完美的人只配当背景板。
2. **锁定具象欲望**——不写「我要成为天下第一」，要写「三个月后宗门大典上当众抽碎退婚长老的脸」；不写「拯救全人类」，要写「今晚凑齐十万块手术费」。越接地气，剧情推进感越强。
3. **极限情境抉择**——人设不是旁白推出来的，是他在生死与道义之间做两难抉择时付出的代价堆出来的。
4. **打造经营锚点**——标志性小动作或专属道具（开大前摸左手小指的伪剑、下完人慢条斯理掏手帕擦眼镜），反复强化，读者一看到就起鸡皮疙瘩。

## 三、代入感三层

1. **感官代入**——让读者通过主角的眼睛去看、耳朵去听，主视角要占到 70% 以上；
2. **情感代入**——最强的代入感永远是曾经的自己（魂穿明末抗击外族，DNA 就动了）；
3. **书中代入**——跟着角色经历出生、饥饿、战斗，建立独一无二的情感连接——读者对人物的情感只会随着剧情深入，这就是好书完结时心里空落落的原因。

逻辑代入（给女孩的食物能获得百倍返还，「圣母」就变成了最聪明的利己主义）是情感代入的前置——给主角的每个选择一个自利的合理动因。

## 四、心理描写五招

1. **生理反馈**——身体比大脑诚实（指甲嵌入掌心、牙齿咬得咯咯作响，镜像神经元让读者亲身代入）；
2. **移情于景**——感官扭曲法：安静教室里钟表声像重锤砸在心头；
3. **心理卡位法**——拆碎揉进动作和对话，留白让读者自己脑补；
4. **言行不一**——极度悲伤往往不是嚎啕大哭而是反常平静；
5. **逻辑链条与潜意识流**——生死关头想的不是宏图伟业，而是清晨出门忘了叫妹妹起床吃早餐。

## 五、对话：四招与三坑

### 四招

1. **身份化语言**——每个角色说话必须带着他过往几十年生活的烙印；
2. **潜台词与词不达意**——海明威冰山理论：对话只是露在水面的 1/8；
3. **打破有问必答**——答非所问、反问压制、情绪切断；
4. **用动作和环境辅助对话**。

### 三坑与优化

1. **情绪标签**——「他愤怒地说」「他开心地说」，读者看到的是标签；改用动作替代：「他把茶杯砸在地上：滚」——一字未提愤怒；
2. **信息倾倒**——「你记得吗，我们三年前在中山大道认识的」（两人都记得的事说给读者听）；把信息藏进冲突：「三年前中山大道那一件，你还欠我一个解释」——信息给了，还多一个悬念；
3. **千人一调**——遮住名字分不出谁说的；给每个角色定一个说话习惯（人狠话少只说短句「不去」；话多的「去去去」停不下来；笑里藏刀的「我还惦记着呢」）。

## 六、外貌与群像

- **外貌只抓一个核心视觉锚点无限放大**，融入动态行为，与性格命运焊死；
- **群像四招**：给每个人贴上记忆钢印（读者记不住名字但记得住标签：一直剥花生、一直擦断刀）/ 用冲突链代替复读机（价值观碰撞产生火花）/ 摄像机的焦点转移法（每个人轮流在属于自己的那一分钟里发光）/ 赋予群像共有的灵魂（水浒的义气、全职的执念、雪中的风骨）。

## 七、顶级反派四维度

1. **从来不认为自己是坏人**——在反派的逻辑闭环里他才是拯救世界的英雄；
2. **拒绝降智制造绝对压迫感**——《诡秘之主》阿蒙无处不在的未知恐惧；
3. **反差魅力**——恶的底色上抹一笔极致的亮色；
4. **落幕必须有仪式感**——「我输了，但我没输给你，我是输给了天书/时代」。

### 高智商反派三模板

1. **布局者**——走一步看十步，所有行动都有双重目的；
2. **循导者**——逻辑自洽的理想主义（「为了拯救一百万人牺牲十个无辜的人这有错吗」）；
3. **佯态者**——藏在身边的影子，最锋利的刀往往从背后刺来。

### 高智商反派三法则

1. **立足立场**——绝不做为恶而恶的疯子；反派眼里主角可能根本排不上号，他针对主角不是为了变态，而是为了宗门百年大比不被灭族。两种信念的厮杀才叫成年人的史诗。
2. **斩草除根**——发现主角是天才，不等成长、不派小喽啰试探，直接派最强战力连夜围杀；灭一个家族是提前半年断粮草、收买亲信、下毒废长老，等对方反应过来大势已去。
3. **利用规则**——杀人从不用自己的刀，用的是大义和规矩（在百姓面前把主角逼成叛国逆贼：动手就是天下公敌，不动手就任人宰割）；甚至主角重伤倒地时温和递上一碗药「你很强大，若肯归顺，一人之下」——杀人诛心。

**终极秘密：最顶级的反派其实就是主角的一面镜子。** 记住：主角的高度，永远由反派的智商决定。反派是深不可测的悬崖，主角才是绝处逢生的神明。

## 八、感情戏三招

1. **制造屏障**——极致的吸引力 + 极致的阻力 = 极致的拉扯：想靠近但理智告诉我必须推开；
2. **词不达意的错位表达**——局部放大法：指尖触碰的半秒钟、连呼吸都停止的静止；
3. **推拉节奏的动态平衡**——试探 → 靠近 → 回避 → 爆发，克制比放肆更有张力。

## 九、人物卡输出格式

为用户设计人物时，按以下结构输出（可直接填入 `assets/story-bible-template.md`）：

```
【人物名】
核心动机：……（发动机，像一根刺）
外在目标：……（导航仪，具体+时间限制）
致命弱点：……
反差感：……（魅力外衣）
经营锚点：……（标志性小动作/专属道具）
说话习惯：……（短句/话痨/笑里藏刀）
极限情境下的选择：……（两难抉择预演）
在书中的功能：……（主角成长线/剧情功能）
```
