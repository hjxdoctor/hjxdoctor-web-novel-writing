# 03 · 大纲与长篇结构

> 用户要列大纲、保字数不崩、搭结构框架、管伏笔，或系统文写崩时，加载本文件。

## 一、活大纲四步法

死大纲是剧情流水账；活大纲的三特征是**驱动力、冲突点、情绪锚点**。

1. **确立情绪核心**——先问「这段要读者什么心情」；
2. **设计冲突阶梯**——一层比一层高；
3. **建立信息差**——标注何时揭哪个伏笔、让谁误会；
4. **细化为长阴卡（章节卡）**——每张卡只记三要素：本章目标、核心冲突、结尾钩子。模板见 `assets/chapter-card-template.md`。

列人名和修炼等级的长篇设定不叫大纲，叫自我感动；能扛住五十万字的大纲是一张精密的闯关地图。

## 二、一句话核心四问

用一句话定义全书主线，回答四问：**是谁 / 他最想得到什么 / 谁在拦着他 / 失败了会怎样**。

注意目标必须具象带数字与对象——不是「我想变强」，而是「三年内夺回祖传股、灭掉屠满门的天罗宗」。写不清这句话，说明主线没立住。

## 三、逆推法大纲（从结局往回推）

不管是整本书还是某个分卷：先给一个结局当「矛点」，然后疯狂提问逆推——这个大 BOSS 是谁？他为什么要被推翻？主角怎么干掉他？单挑需要练到什么境界？这就像思维导图，一个核心问题衍生三个子问题，三个子问题又衍生九个孙子问题。

写大纲其实就是在预言你的小说：不要去想我该怎么开头，应该去想我该让主角在哪里结束。

先定终点（主角最终赢还是输、得到什么失去什么），中间该埋什么线、在哪冲突、哪反转才清楚。

## 四、四级结构（几百万字不烂尾的骨架）

- **一级结构**：起承转合，1-2 万字一个循环；
- **二级结构**：多个单元组成一卷，可埋大量伏笔形成中期期待；
- **三级结构**：多卷组成更高层起承转合（《诡秘之主》前四卷三百万字共讲「复仇」一个主题）；
- **四级结构**：全书八卷合看仍是一个起承转合。

结构套结构、套路之上还有套路，几百万字讲一个完整封闭故事而不烂尾。

## 五、四步骨架法（五十万字闯关地图）

1. **锚定终极主线**——一句话定义主角终极目标，它是指南针，后面每个剧情、每个角色都服务于它；
2. **拆解阶段副本**——五十万字 ≈ 五个十万字中型副本串联（新手村破局 → 中门崛起 → 快遇中峰 → ……），每阶段只聚焦解决当前副本的核心矛盾，不可能卡文；
3. **配置核心死敌与阶段阻碍**——每副本明确「终极死敌是谁、本副本小死敌凭什么压制主角、主角怎么翻盘」；不是主角推着剧情走，是反派制造的危机逼主角反击；
4. **主线钩子备忘录**——专门记录「第一章捡到的锈铁片、第十五万字的残卷、随手救下的落魄老者、第三十万字发现他是隐世大佬」，草蛇灰线伏埋千里，后期自然有内容可写。

**每个阶段四件事**：当前目标是什么、最大阻碍是谁、主角要付出什么代价、阶段结束打开什么新问题。到章节层，一句话大纲就够：主角为了什么做什么，结果怎样，留下什么悬念。

## 六、整本书的四个关键转折

1. 什么把主角从原有生活里硬拽出来；
2. 他为什么再也回不去（回头代价是什么）；
3. 他发现真相和自己想的不一样（世界观被打碎）；
4. 最终必须做出一个最难的选择。

## 七、三线并行

- **主线** = 读者的终极期待（火车头）；
- **支线** = 故事的血肉、节奏的调节阀；
- **暗线** = 故事的灵魂、读者的肾上腺素（高级伏笔寄生在支线里）；
- 大高潮必须三线同秒撞击。

**多线五招**：锚点归衣法、悬念钩子交替法、信息差不对称、节奏错位、漏斗式汇聚。实操妙招是做一张平行时间轴表格。

**剧情四支柱**：新颖社会身份（汇集前期矛盾）+ 惊天隐藏身世（引爆后期高潮）+ 爽快超级外挂（前期爽感）+ 读者超爱的人设（后期情感共鸣）。

## 八、两种剧情构建法

1. **计划意外构建法**——定目标 → 制定计划 → 遭遇意外 → 目标升级 → 制定新计划；整个故事就是无数个单元的循环，主角的成长是计划和意外逼出来的；
2. **大高潮逆推法**——先写全书最爽的那一幕当「高潮原型」，解构它，再逆推小高潮、爆发点。

## 九、另外两种好用的构思法

- **故事桩串联法**（文笔不好也能写小说）——把脑子里零散的画面像打桩一样定下来，再用设定人物背景串联、添加逻辑补丁、制造反转推向高潮。创作不是无中生有，而是发现和连接。
- **故事细胞分裂法**——找到充满张力的故事核（霸总的控制欲 vs 妻子的自由魂）→ 启动地点、人物、动机三大引擎 → 编制主线+支线的冲突网，从一个核心创意裂变出百万字长篇。

## 十、框架 = 阵营手牌法

把小说看成一局牌局：主角、反派、吃瓜群众各是一个阵营，剧情推进看大家手里有什么牌、按什么顺序打。垫脚石的艺术就是让观众和敌人先把牌出尽、觉得自己赢定了，主角再掀桌子。

## 十一、伏笔管理三习惯

1. **埋完马上记下来**——单开一页写清「计划埋的、计划收的、回收方式」，收完一个划掉一个；
2. **埋之前先想好怎么收**——这张回收是给反转、打脸还是揭开信息？想不出回收的样子就先不埋；
3. **回收之前让它再出现一次**——隔了四十多章读者早忘了，在回收前几章让它「轻轻冒个头」（被人多看一眼、夜里发光），回收那一刻读者才一拍大腿「原来如此」。

## 十二、警惕「大纲绑架」

角色会长出自己的意志。当主角选择偏离路线，死抱表格用降智剧情拉回既定轨道，大纲就从救命稻草变成禁锢灵性的脚镣。正确姿势：**锁定创作方向，放开创作过程**——像修高速公路，知道起点、终点和三四个核心爽点，剩下的路让角色的欲望自己去撞。

## 十三、系统文专题：为什么十本九本写崩

三个死穴：

1. **系统成了爹，主角成了纯打工仔**——系统发任务主角跑腿、系统给神装主角升级；读者是来看人物成长的，不是来听设定广播的。主角必须有自己的执念，系统只是辅助，绝不能当保镖。
2. **数值通胀太快，喂死读者的多巴胺阈值**——开局送神器功法极品装备，奖励像粉尘一样不值钱，后期送他一个银河系也毫无感觉。大神玩的是规则和机制，让主角卡系统 bug，远比粗暴数值刺激爽上一百倍。
3. **危机毫无博弈感**——反派当靶子、系统秒刷解毒丹、敌人刚露面就家破人亡被收服。没有博弈，哪来的爽感。

结论：写不好系统文不是脑洞不够大，而是把外挂当成了故事本身。
