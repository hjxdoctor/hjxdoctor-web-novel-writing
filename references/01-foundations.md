# 01 · 底层逻辑、期待感、爽点与情绪心理学

> 猫神写作方法论的地基部分。用户质疑「为什么没人看」「什么是爽点」「读者为什么弃书」时加载本文件。

## 一、底层逻辑：网文是情绪产品，不是文学作品

四条创作纪律，按优先级排序：

1. **市场先于表达**——开书前先去各大榜单泡几天：读者在为什么样的书着迷、什么样的书名有点击欲望。搞清楚客户爱吃什么才能精准上菜。月入过万的作者开书前想的不是「我想表达什么」，而是「市场需要什么」。
2. **情绪先于剧情**——爆款书从头到尾只贯穿一种主情绪（《斗破苍穹》= 落魄少年如何向世界证明自己）。散乱堆情绪像大杂烩，什么味都有就是不好吃。别盯着套路框架，去写读者现实中无法呐喊的痛苦、无法实现的欲望——成为他的互联网嘴替。
3. **换位先于自嗨**——写每一段都启动陌生人视角：刚下班累得半死、只有三分钟耐心的读者，凭什么看这堆设定？每场戏先定情绪指标；省略「抑」直接一拳打飞反派，那叫无聊。网文的第一属性是娱乐产品，读者累了一整天打开手机，不是来听人性哲学、不是来看半小时落叶描写的。
4. **迭代先于完美**——知道和做到之间隔着一条无法逾越的银河；低水平的重复不叫经验，叫浪费生命。

新人优先级：**最该先练的不是文笔，是冲突和欲望**。文笔是血肉，冲突和欲望才是骨头；骨头立不住，血肉再漂亮也撑不起人物。训练法：拿写不下去的那一章，只回答三个问题——主角最想得到什么？谁在阻止？失败了会立刻失去什么？

## 二、期待感工程学：信息差与三层钩子

顶级网文就是一个接着一个的勾子，这个勾子叫**信息差**：我知道，但先不告诉你，让你猜，让你急。

### 上瘾模型四步（源自互联网产品设计）

- **触发**——勾住读者自己的欲望（逆袭打脸、女神倒追），别教育读者，点燃他们最渴望、最愤怒的点。
- **行动**——简单才能无脑重复。开篇拒绝说明书式设定轰炸，用最少的脑力获得第一次爽。
- **奖励**——关键是随机性。稳定发工资会腻，拆龙蛋式的惊喜才有期待感。
- **投入**——读者难割舍的不是钱和时间，是积累的虚拟财富（装备、排名、势力、地位），财富越多弃书阻力越大。

### 三层期待设计法

| 层级 | 手法 | 读者状态 |
|---|---|---|
| 微观 | 危机和信息差——制造一个即将爆发的矛盾，在高潮前戛然而止 | 「急」 |
| 中观 | 阶段性目标和压力——给主角一个具象化的阶段性大奖（如三年之约），让读者看到希望但别让他轻易得到，像驴眼前吊着的胡萝卜 | 「缠」 |
| 宏观 | 终极悬念和世界观——想写两三百万字得有「天坑」式的终极悬念，每隔几万字给出一个新碎片，像拼图一样让读者痴迷 | 「迷」 |

三层叠加，就像优雅的渣男忽冷忽热、若即若离；当读者拍着桌子喊「快点更不然寄刀片」时，你就真正掌握了成神的秘籍。

### 信息差的两种玩法

1. **主角知道、全世界不知道**——扮猪吃老虎，读者等着看主角暴爽。
2. **读者知道、主角不知道**——上帝视角焦虑：反派在酒里下毒还阴冷笑着，读者想大喊「别喝」，焦虑转化成阅读动力。

## 三、爽点设计：情绪满足的底层逻辑

**爽点绝对不是装逼打脸，而是情绪满足。**

- **爽的本质是过程不是结果**——人们看修马蹄、洗地毯、切肥皂的视频停不下来，图的不是结果而是过程：把不归整的东西变归整，满足了内心对秩序和掌控的需求。学霸重生文火的原因同理：读者在主角一张张背单词的过程里代入了，仿佛把自己曾经没背下来的课文、没做对的题全部搞定——这是遗憾被弥补的满足感。

### 爽点四类放大器

1. **反差**——丑女化妆变美女、农妇变金牌律师；反差越大情绪越炸裂，网文里就是扮猪吃老虎。
2. **仪式感**——主角突破别干巴巴写「他升级了」，要写天降异象、方圆百里高手震惊，像游戏里抽到神卡时全服滚动播报。
3. **社交认证**——爽感的本质不是获得什么，而是别人知道你获得了什么并表示羡慕嫉妒恨：学了新技能就去大比一招秒杀，赚了大钱就回老家在亲戚面前把钱砸桌上。
4. **随机性**——人对奖励本身上瘾，对「即将开出奖励那一瞬间的期待感」上瘾；抽卡游戏几万几万地氪，就是因为永远不知道下一张是 SSR 还是垃圾。

### 力量感三源泉

1. **极致的驱动力**——不是「我想成为天下第一」，而是「不成为天下第一，我和全家都会死无葬身之地」；力量感来源于恐惧和绝境。
2. **极致的绝望**——敌人要写成一座翻不过去的大山：体制、神明、命运、阶级。对手越强，主角那一拳才越有分量。
3. **力量的代价**——大神写书主角获得力量靠献祭：克莱恩成了愚者，却失去了普通人的平静和回家的希望。没有痛苦的成长不动人。

## 四、情绪拉扯与读者心理学

### 四层情绪拉扯

1. **期待与落差对撞**——给一个甜枣、删一个巴掌、再来意想不到的惊喜。
2. **理智与情感博弈**——角色「想做但不能做、不想做但不得不做」；给角色设无法调和的矛盾点，内耗产生张力。
3. **信息差错位**——读者知道真相、主角蒙在鼓里，误会解除时的宣泄感就是打赏理由。
4. **灵魂共鸣的情绪美学**——主角抗争宿命（「我命由我不由天」），读者看完沉默半天，这就叫封神。

### 心理学武器库

- **蔡格尼克效应**——人对未完成事件的记忆远深于已完成：永远不要在情绪或事件圆满时收尾，要在高潮来临前掐断。
- **间断性强化**——斯金纳实验：小白鼠按按钮有时得食有时不得，会陷入疯狂点击。每章都打脸读者会腻，偶尔的空手而归才能吊出赌徒心态。
- **认知失调**——全世界都瞎了眼的反差越大，主角扭转认知那一刻的爽感越大。
- **巴纳姆效应**——开篇写「最大公约数」式的情绪：怀才不遇的孤独、被亲戚看不起的憋屈，读者下意识觉得「这写的简直就是我」。
- **镜像神经元效应**——写主角的生理反应：指甲嵌入掌心、牙齿咬得咯咯作响，读者才能在大脑中亲身代入。
- **锚定效应**——先写普通人辛苦一年才赚十块，主角一万块的震撼力才出来。
- **峰终定律**——每段剧情中间必须有一个情绪高峰，结尾必须有余韵或悬念。

### 代入感四招

1. **感官沉浸**——把视角贴在主角眼球上，写看到的、听到的、闻到的、皮肤触碰的质感。
2. **情绪同步**——别写「主角很愤怒」，写愤怒时的生理反应和瞬间念头。
3. **真实的逻辑细节**——克莱恩先数口袋里的铜板算能买多少黑面包，缺钱的局促感无论学生还是打工人都能理解。
4. **价值认同**——让读者想成为主角：「如果我是他，我也会这么做」。

## 五、留存本质：读者追的是「盼头」

读者追的不是文字，是下一章还有没有盼头（报仇、翻身、赢反派、升级、得宝、爽感）。这件事在推进，文笔一般也追；这件事一停，场面再热闹也弃书。

**盼头丢失的三种情况**（写崩的三种典型死法）：
1. 承诺的线中途改道——说要报仇突然去谈恋爱；
2. 目标太大没有分阶段结果——连着十几章走流程；
3. 主角被剧情推着走，不再主动要一样东西。

**每章自查四问**（写作中与改稿时通用）：
1. 这一章主角最想得到什么？
2. 谁在拦着他？
3. 他付出了什么代价？
4. 章末留下了什么新问题？

答不清第三问（代价）的章，通常是淡水章。
