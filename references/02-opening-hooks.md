# 02 · 开篇与留存：黄金三百字实战

> 用户要写开篇、前三章、书名简介，或抱怨「写了十几万字没阅读」时加载本文件。

## 一、黄金三百字（不是黄金三章）

读者看网文就是来看主角怎么装逼的；开头前三百字抓不住眼球，读者就像滑走短视频一样把你的书划死。前三章是生死线：读者看完三章只判断一件事——还要不要点下一章。很多书写了十几万字没阅读，其实读者第三章就走光了，后面是写给空气看。

对「黄金三章」的辩证态度：平台算法逼出的「三章必打脸」正在毁掉长篇生态——前三章把情绪爆点全炸光，导致十万字全面崩盘。正确做法是把极致情绪密度压缩进前三章，同时给长线留钩子。

## 二、危机应对法：开篇第一句话就让主角活不下去

### 三要

1. **快速交代主角和主境**——时间地点人物一句话说明白；
2. **快速闪述核心冲突**——危机必须立刻产生期待感；
3. **快速亮出金手指**——危机是问题，金手指就是解决问题的可能性。

### 三不要

1. 不要大段背景交代；
2. 不要多余设定；
3. 不要出现多余人物——开篇除了主角，其他人连拥有名字的资格都没有，只能叫「那个退婚的女人」「那个想杀我的管家」。

### 黄金开篇三步法

1. **核心钩子（刀架脖子）**——开篇第一句不铺风花雪月，直接进入极限冲突的当下（例：「推开门那一刻，本该在火葬场火化的妻子，正坐在沙发上对我笑」）；
2. **金手指破局（底牌亮出）**——读者跟主角憋屈最多三分钟，必须在第一章中段亮出翻盘资本（系统提示音、神秘玉佩），给的是「复仇破局的确定性」而非马上无敌；
3. **追读断章（悬念断头）**——第一章结尾掐在行动最关键节点，别写主角称体重、心中发誓，要写「主角扶下眼镜，双眼血红，一脚踹开仇家的大门——卡」。

### 前三章必须立住的三句话

主角是谁、他想要什么、现在最大的麻烦是什么。三句说不清，设定再完整也没用——读者不是来读说明书的。

### 开篇三雷区（新手最高发）

1. 查户口式交代背景（「大楚王朝历经三百年，分九州四海」）；
2. 梦醒了照镜子练字（「少年猛地惊醒，看着镜中清秀的脸」）；
3. 无危机日常流水账（早上吃包子路上遇灵居，聊半天不沾主线）。

## 三、十种开篇模板（大神小白都能直接套用）

| 模板 | 要点 |
|---|---|
| 重生流 | 重点不是重生，是重生前的鞭尸 |
| 退婚流 | 天才变废材，辱得越狠后面打脸越爽 |
| 危机流 | 天崩开局 |
| 困境流 | 封闭绝望环境 |
| 紧迫流 | 开局即动作戏 |
| 系统流 | 三行内响起「叮」的一声 |
| 好奇流 | 开局一具尸体一个离奇现场 |

（其余：马甲流、开局即巅峰流等，按「危机应对法」三要三不要自查即可。）

## 四、开篇十大毒点

踩中一个，书就废了：背景设定大科普 / 熟悉的碎碎念 / 毫无意义的日常琐事 / 逻辑自相矛盾的降智 / 主角性格太圣母 / 信息量过载的群戏 / 大段的梦境或回忆 / 系统提示喧宾夺主 / 文笔过分堆砌 / 目标感缺失。

## 五、书名与简介是门面

读者给一本新书的注意力只有一两秒。

- **书名万能公式** = 具体爽点 + 巨大反差 + 核心身份。
- **简介**：别写连续闻，写得像广告词，前三行必须抛出悬念。
- 预期管理纪律：书名说有外挂，第一章外挂就得上线；简介说要复仇，第三章仇人的脸就得被打肿——「后面更精彩」在网文世界不存在。

## 六、留存自查

写完前三章与每一个卡点，逐条核对：

1. 三句话立住了吗（主角是谁/要什么/最大麻烦）？
2. 盼头（报仇、翻身、赢反派、升级、得宝、爽感）在持续推进吗？
3. 有没有踩三雷区、十大毒点？
4. 第一章结尾是断在刀尖上，还是断在主角称体重？
5. 书名+简介两秒内能说清核心卖点吗？
