# 网文写作技能包（Web Novel Writing Skills）

> 中文网文写作技能合集，聚焦大神级别的写作技巧与设计。适用于 WorkBuddy / Claude 等 AI 助手的 Skill 体系。

## 技能列表

### 1. web-novel-writing（网文写作方法论 v2.0）

通用网文写作方法论，蒸馏自四位抖音写作博主的教程，形成「实战 + 理论 + 公式」三层体系：

- **猫神写作 + 码字如有神** → 商业爽感方法论地基
- **尘三昧** → 文学理论与叙事美学
- **网文资料菌** → 公式化实战工具箱

覆盖：选题开书、大纲结构、人设工程、节奏爽点、卡文救场、拆书对标、去 AI 味、商业化决策等完整链路。

> 见根目录 `SKILL.md` 与 `references/`、`assets/`

### 2. xuanhuan-wenbi（玄幻文笔流方法论）

玄幻/仙侠小说的「文笔流」风格方法论，蒸馏自十位网文圈公认「文笔流」作者的文笔精髓：

猫腻、烟雨江南、烽火戏诸侯、萧鼎、老猪、江南、知秋、徐公子胜治、爱潜水的乌贼、宅猪。

三层结构：

- **文笔美学六维**（理论层）——意境余韵、人物刻画、语言节奏、史诗感、苍凉悲壮、语言质感
- **作者风格画像**（风格层）——十位作者各自的文笔指纹、核心技法、代表性意象、模仿要点
- **句式意象库**（实战层）——可套用的句式模板、意象词典、节奏公式、去 AI 味清单、自查清单

> 见 `xuanhuan-wenbi/` 目录

## 安装

将对应技能的整个目录复制到你的 AI 助手的 skills 目录即可：

- WorkBuddy 用户级：`~/.workbuddy/skills/`
- WorkBuddy 项目级：`<项目>/.workbuddy/skills/`
