# 章节卡（长阴卡）模板

> 每写一章前花 5 分钟填好；只记三要素，拒绝剧情流水账。
> 出处：猫神写作「活大纲四步法」第 4 步——每张卡只记本章目标、核心冲突、结尾钩子。

### 每章自查四问

- [ ] 主角付出了什么代价？（没有代价 = 淡水章，重写）
- [ ] 本章结束读者会不会想知道下一章结果？
- [ ] 断章位置是否在情绪最高点 / 悬念揭晓前一秒？
- [ ] 弹簧压够了再打脸？大战后给呼吸感？
