# 03 · 句式意象库

> 用户需要"具体怎么写"时，读本文件。提供可直接套用的句式模板、意象词典、节奏公式，以及文笔自查清单。所有句式都配套「改前 vs 改后」对照思路。

---

## 一、句式模板（按场景）

### 1. 意境收尾句（猫腻式余韵）

**公式**：`一个无声动作 + 一个景物/物件`，情绪不点破。

- 改前："他望着远去的背影，心中百感交集。"
- 改后："他站在原处，望着那道背影渐渐隐入山雾。风起了，吹动了衣角。"

**变体**：
- 「雪落在……上」句式："雪落下来，覆了他满肩，也覆了那柄断剑。"
- 「灯/酒/茶」收尾："炉上的茶凉了。灯花爆了一下，又归于寂静。"

### 2. 悲壮宣言句（烽火/江南式封神台词）

**公式**：`短促有力的宣言 + 留白`，一句话把精神内核钉死。

- "铁甲依然在。"
- "剑来。"
- "虽千万人，吾往矣。"

**使用时机**：人物绝境/高光时刻，一句顶千言。忌滥用，一本最多几次。

### 3. 史诗纵深句（烟雨江南式命运感）

**公式**：`当下场景 + 时间闪回/预叙`，拉长时间维度。

- "多年以后，当人们提起那场大雪，仍会记得那个持剑的少年。"
- "他不知道，这一剑落下的刹那，一个时代就此终结。"

**变体**：「那一刻他尚不知道……」句式，制造命运悲怆。

### 4. 苍凉收束句（大战后的沉默）

**公式**：`不写胜利喜悦，写满目疮痍 + 幸存者沉默`。

- "战场安静下来。没有欢呼，只有风声，和满地再也站不起来的人。"
- "他赢了。可他回头时，身后已没有一个熟悉的面孔。"

### 5. 少年意气句（江南式热血）

**公式**：`少年 + 理想 + 现实的反差`，先扬后抑。

- "那年的他，以为仗剑就能平天下，以为一腔热血就能抵过整个时代的寒。"
- "少年不识愁滋味，只道此去，必是星辰大海。"

### 6. 高人装 B 句（徐公子式底蕴）

**公式**：`不靠武力数值，靠见识/格局/涵养`。

- 改前："他修为高深莫测，全场震惊。"
- 改后："他放下茶盏，说了句'天地不仁'。满座皆寂，无人敢接。"

## 二、意象词典（按维度）

### 意境/余韵类
雪、雨、山、剑、灯、酒、茶、炉火、孤舟、寒江、青衫、断桥、残月、落叶、远山、雾。

### 史诗/宏大类
山河、众生、轮回、因果、苍穹、群星、深渊、神庙、王朝、战场、铁骑、烽火、旗帜。

### 苍凉/悲壮类
大雪、孤城、老卒、断剑、风沙、落日、残阳、枯骨、寒鸦、长河、古道、白发。

### 少年/热血类
少年、理想、热血、倔强、远方、星辰、铁甲、战旗、誓言、锋芒、晨曦。

### 清雅/底蕴类
书、茶、棋、道、玄理、竹、琴、松、莲、鹤、钟声、檀香。

### 使用原则
1. 意象是**情绪的载体**，不是装饰。选意象前先想清楚：这一处要传达什么情绪。
2. 忌堆砌：一段里 2-3 个意象足够，多了就空。
3. 同一意象可反复出现形成"贯穿线"（如全书反复出现的"雪"，成为情感符号）。

## 三、节奏公式

### 紧张（打斗/追逐/危局）
- **短句 + 强动词**，一个动作一句。
- 例："剑起。风啸。血溅。他踉跄后退，剑尖点地，稳住身形。"
- 动词用：劈、斩、掠、旋、刺、崩、震、落、踏、闪。

### 抒情（回忆/意境/情绪）
- **长句 + 意象叠加**，舒缓绵长。
- 例："他想起很多年前的某个雪夜，也是这样安静，只是那时，灯下还有一个人等他回来。"

### 张弛交错
- 一段之内**先长后短**或**先短后长**，制造落差。
- 忌：整章全短句（像枪战片，累）或全长句（像念经，闷）。

## 四、去 AI 味改稿清单

逐条排查产出，出现即改：

| AI 味/套话 | 替换为 |
|-----------|--------|
| "不禁""不由得""下意识地" | 直接写动作，删掉这些过渡词 |
| "心中暗想""内心翻涌" | 换成具体的身体反应或景物 |
| "一股暖流/寒意涌上心头" | 换成"指尖发冷""喉咙发紧" |
| "十分/非常/极其 + 形容词" | 删程度副词，用具体代替 |
| "他感到……"（过滤词） | 删"感到"，直接写感受的画面 |
| 形容词堆砌（三个以上并列） | 保留最准的一个，其余删 |
| "眼中闪过一丝……" | 换成具体的眼神动作（眯眼、移开、垂眸） |
| "浑身一震""心头一颤" | 换成独特的具体反应，避免复读 |

## 五、文笔自查清单（产出后逐条核对）

- [ ] 情绪是否藏在动作/景物里，而非直说？
- [ ] 是否有「改前 vs 改后」的具体对照，而非只讲原则？
- [ ] 句子长短是否有节奏变化，而非全程一个节奏？
- [ ] 意象是否精当（2-3 个），而非堆砌？
- [ ] 是否有 AI 味套话（不禁、心中暗想、涌上心头等）？
- [ ] 结尾是否留有余韵，而非写满？
- [ ] 每个重要人物是否有"标志性细节 + 封神台词"？
- [ ] 信息密度是否够（一段话是否同时做到造氛围、立人设、埋伏笔）？
