# 玄幻文笔流方法论（Xuanhuan Wenbi）

## Overview

本技能把十位「文笔流」作者的文字功力，拆解成三层可复用的资产：

1. **文笔美学六维**（`references/01-文笔美学六维.md`）——把「文笔好」拆成六个可观测、可操作的审美维度：意境与余韵、人物刻画、语言节奏、史诗感、苍凉与悲壮、语言质感。这是**理论层**，回答「好文笔到底好在哪」。
2. **作者风格画像**（`references/02-作者风格画像.md`）——十位作者各自的文笔指纹、核心技法、代表性句式意象、适用场景、模仿要点。这是**风格层**，回答「想写出猫腻/烽火/烟雨的味道该怎么做」。
3. **句式意象库**（`references/03-句式意象库.md`）——可直接搬用的句式模板、意象词典、节奏公式、改稿清单。这是**实战层**，回答「这一句到底怎么写」。

三层关系：**美学六维是"道"，作者画像是"门"，句式意象库是"术"**。先定风格方向（学谁），再按维度拆解（学什么），最后落到句式意象（怎么写）。

## 何时使用

- 用户想让玄幻/仙侠小说的**文字更有质感、意境、余韵**，而非只推剧情
- 用户想**模仿某位作者的文笔**（"写得像猫腻一点""要烽火那种苍凉感"）
- 用户觉得自己的文字**干巴巴、AI 味重、辞藻堆砌却无神**，想提升文笔
- 用户需要**具体的句式、意象、节奏**来改写某段文字
- 用户在写**意境戏、情绪戏、人物出场/离别、战争史诗、少年意气**等需要文笔撑起来的场景
- 用户想**拆解某位作者的文笔**，学习其可复用的技法

## 核心工作流（四步）

1. **定位风格方向**：先判断用户是否点名了某位作者/某种风格。点名 → 直接读 `02-作者风格画像.md` 对应条目；没点名但描述了感觉（"要苍凉""要有意境""要史诗感"）→ 读 `01-文笔美学六维.md` 对应维度定位。
2. **拆解到维度**：无论学谁，最终都要落到「意境/人物/节奏/史诗感/苍凉感/质感」这六维中的一到两维，作为本次改写的主攻方向。不要面面俱到。
3. **落到句式意象**：从 `03-句式意象库.md` 选取对应该维度的句式模板和意象，给出「改前 vs 改后」的具体对照。禁止只讲原则不给具体文字。
4. **文笔自查收尾**：用 `03-句式意象库.md` 末尾的「文笔自查清单」逐条核对产出，重点排查 AI 味（空泛形容词、辞藻堆砌、无画面感、节奏单一）。

## 关键原则（贯穿所有产出）

1. **文笔 = 意境 + 克制 + 节奏**，不是辞藻堆砌。宁可平实有神，不可华丽无骨。
2. **展示优于讲述**：情绪藏在动作、景物、细节里，不直说"他很悲伤"。
3. **信息密度是分水岭**：一笔多用——一段话同时立人设、造氛围、埋伏笔。
4. **长短句交错**：用句子长度控制呼吸，紧张用短句，抒情用长句，忌讳全程一个节奏。
5. **一切景语皆情语**：环境描写永远是人物内心的外化，不写无意义的风景。
6. **给出「改前 vs 改后」对照**：所有文笔建议必须落到具体文字对比，拒绝空谈。
